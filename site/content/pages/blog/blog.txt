A demo **content stream**. This page uses the `blog` template and declares
`AllowedChildTemplates: article` in its front matter — so only pages using the
`article` template can be created beneath it. Try adding a plain `page` child in
the admin and you'll get a clear error.

Articles below are listed automatically via the `child_pages()` Twig helper.

  body: |
    A page template extends `layout.twig` and fills its blocks:

    ```twig
    {# site/templates/page.twig #}
    {% extends 'layout.twig' %}
    {% block title %}{{ page.metatitle ?? page.title }} · {{ app.name }}{% endblock %}
    {% block body %}
      <h1>{{ page.title }}</h1>
      {{ content|raw }}
    {% endblock %}
    ```

    ## Variables

    | Variable | What |
    |---|---|
    | `page` | `title`, `urlPath`, `slug`, `template`, `status`, `state`, `isLive`, `listing`, `publishedAt`, `author`, `sort`, `extra` (other front matter) |
    | `content` | the rendered body — print with `\|raw` |
    | `fields` | typed [page fields](/guide/page-fields) |
    | `preview` | true when an editor views a page that is not live |
    | `app` | `name`, `baseUrl`, `adminPath` |
    | `visitor`, `access` | see [Members](/guide/members) |
    | `csrf` | for POST forms, see [Forms](/guide/forms) |

    ## Helpers

    | Helper | Returns |
    |---|---|
    | `top_level_pages()` | the main menu — this site's header |
    | `nav_pages('/path')` | a submenu |
    | `child_pages('/path')` | children for a listing — the [Blog](/blog) |
    | `page('/path')` | one live page or `null` |
    | `page_fields(page)` | typed fields of any page — the [Shop](/shop) cards |
    | `collection('name')`, `collection_item('name', 'slug')` | [collections](/guide/collections) |
    | `render_collection_item(item)` | an item's body as HTML |
    | `src\|thumb(w, h, fit)`, `src\|thumb_srcset([…])` | [thumbnails](/guide/media) |
    | `action_state('name')` | what a [site action](/guide/forms) flashed |
    | `text\|markdown` | Markdown → HTML, like a text block: page-local images and thumbnails *(≥ 0.10.3)* |

    The `markdown` filter is how a block gets a rich-text field — the
    `callout` block prints its text with `{{ block.body|markdown }}`. Images
    resolve against the page being rendered; pass another page or a
    collection item to resolve against that one:
    `{{ item.extra.intro|markdown(item) }}`. Raw HTML in the text is escaped.

    If a block template throws, the block renders as
    `<!-- block:<type> render error -->` and the error goes to
    `writable/logs/app.log` (with `DEBUG=true` also into the comment).

    ## Special templates

    - `layout.twig` — the base; never offered as a page template.
    - `404.twig`, `410.twig` — error pages. Try [/nothing-here](/nothing-here)
      and [an archived page](/guide/visibility/archived).
    - `login.twig` — the member sign-in page at [/login](/login).
    - `<template>.blocks.yaml` — the manifest next to a template:
      page fields, allowed and default blocks.

    The footer of every page names the template that rendered it.

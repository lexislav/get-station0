![Station0](home.png)

**Station0** is a flat-file CMS built on Slim 4 and Twig 3. Every page of this
site is a plain text file in `site/content/pages/`, every look is a Twig
template in `site/templates/`, and the admin at [/admin](/admin) edits the same
files. A database (SQLite) holds only user accounts.

This demo site documents itself: each page explains the feature it is built
with, and the [Guide](/guide) walks through all of them in order.

## This page

The homepage is the only page whose file sits directly in
`site/content/pages/` — here `page.txt`, so it uses the `page` template. Its
body is plain **Markdown**. The image above is `home.png`, a file in the same
folder; the body refers to it by its bare name and Station0 serves it at
`/media/~/home.png`, resized to fit (see [Media](/guide/media)).
